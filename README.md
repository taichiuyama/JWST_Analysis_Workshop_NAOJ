# JWST_data-download_tutorial

This repository is made for participants of the JWST data analysis workshop held at NAOJ, June 2-4 2026.

https://sites.google.com/view/jwst-data-analysis-2026/home?authuser=0

This tutorial basically follows SpaceKLIP documentations (https://spaceklip.readthedocs.io/en/latest/tutorials/tutorial_NIRCam_reductions.html, except for the section about data download. Also it is made for those who do not have MAST API TOKEN which is rqeuired when downloading data using jspy_download.py or spaceKLIP.mast.download_files

If you would like to access the hyperlinked sites in the presentation slides, please download it to your local machine and open the PDF file.
